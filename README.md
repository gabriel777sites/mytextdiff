# MyTextDiff

A simple tool to compare two texts or files and see what changed.

**Website:** https://mytextdiff.com

All processing happens locally in the browser. Nothing you paste or upload is sent to a server.

## Features

- Line, word and character comparison modes
- Option to show only the changed lines
- Options to ignore spaces, empty lines, case and trailing whitespace
- File upload
- Export the result as PDF
- Free, no sign-up

## Status

The tool works best for plain text right now. Support for code (language-specific
handling and highlighting) is still a work in progress.
